# Спортмастер Wallet — интерактивный прототип

Статический сайт на русском языке. Откройте `index.html` в браузере.

Все сценарии оплаты и возврата на странице демонстрационные; реальные платежи не выполняются.

Для GitHub Pages включите **Settings → Pages → Deploy from a branch**, выберите `main` и папку `/ (root)`. После публикации GitHub покажет ссылку на сайт.
